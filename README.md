# timeout-policy

Public-facing privacy policy + support page for the **Timeout** mobile party game. Hosted via GitHub Pages.

The app source lives in a separate (private) repository. This repo only contains user-facing legal/support docs that need a stable public HTTPS URL for Play Store / App Store listings.

URLs (after enabling GitHub Pages on this repo):

- `https://maniae.github.io/timeout-policy/` — landing page
- `https://maniae.github.io/timeout-policy/privacy-en` — Privacy Policy (English)
- `https://maniae.github.io/timeout-policy/privacy-fr` — Politique de confidentialité (français)
- `https://maniae.github.io/timeout-policy/support` — Support
